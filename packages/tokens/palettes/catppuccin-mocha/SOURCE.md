# Catppuccin Mocha

NostalgiaUI's `catppuccin-mocha` palette is inspired by Catppuccin's Mocha flavour.

- Source: https://github.com/catppuccin/palette
- Licence: MIT
- Licence file: https://github.com/catppuccin/catppuccin/blob/main/LICENSE

Catppuccin is a brand of its own, so this palette is described as inspired by
it rather than presented as the theme itself.

Mapped from the published `palette.json` rather than imported from a VS Code
theme file, because the Catppuccin VS Code port generates its theme JSON at
build time and commits none. `palette.json` is what the port itself is built
from.

## Primitives taken

| NostalgiaUI primitive | Value     | Catppuccin name |
| --------------------- | --------- | --------------- |
| background            | `#1e1e2e` | base            |
| foreground            | `#cdd6f4` | text            |
| selection             | `#45475a` | surface1        |
| keyword               | `#cba6f7` | mauve           |
| string                | `#a6e3a1` | green           |
| function              | `#89b4fa` | blue            |
| comment               | `#6c7086` | overlay0        |
| error                 | `#f38ba8` | red             |
