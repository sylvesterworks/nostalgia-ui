# Dracula

NostalgiaUI's `dracula` palette is inspired by the Dracula theme.

- Source: https://github.com/dracula/dracula-theme
- Licence: MIT
- Licence file: https://github.com/dracula/dracula-theme/blob/master/LICENSE

Dracula is a trademark and a brand of its own, so this palette is described as
inspired by the theme rather than presented as the theme itself. The colour
values are the published palette; nothing else from the project is used.

## Primitives taken

| NostalgiaUI primitive | Value     |
| --------------------- | --------- |
| background            | `#282a36` |
| foreground            | `#f8f8f2` |
| selection             | `#44475a` |
| keyword               | `#ff79c6` |
| string                | `#50fa7b` |
| function              | `#f1fa8c` |
| comment               | `#6272a4` |
| error                 | `#ff5555` |
