# Nord

NostalgiaUI's `nord` palette is inspired by the Nord theme.

- Source: https://github.com/nordtheme/nord
- Licence: MIT
- Licence file: https://github.com/nordtheme/nord/blob/main/license

Nord is a brand of its own, so this palette is described as inspired by the
theme rather than presented as the theme itself.

## Primitives taken

| NostalgiaUI primitive | Value     | Nord name               |
| --------------------- | --------- | ----------------------- |
| background            | `#2e3440` | nord0                   |
| foreground            | `#d8dee9` | nord4                   |
| selection             | `#434c5e` | nord2                   |
| keyword               | `#81a1c1` | nord9                   |
| string                | `#a3be8c` | nord14                  |
| function              | `#ebcb8b` | nord13                  |
| comment               | `#616e88` | between nord3 and nord9 |
| error                 | `#bf616a` | nord11                  |
