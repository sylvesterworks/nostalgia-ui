# Solarized Light

NostalgiaUI's `solarized-light` palette is inspired by Solarized Light by
Ethan Schoonover.

- Source: https://github.com/altercation/solarized
- Licence: MIT
- Licence file: https://github.com/altercation/solarized/blob/master/LICENSE

Included from the first milestone specifically because it is a LIGHT palette.
Shipping one light palette from day one stops dark mode assumptions from
settling into the era definitions, where they would be expensive to remove.

## Primitives taken

| NostalgiaUI primitive | Value     | Solarized name |
| --------------------- | --------- | -------------- |
| background            | `#fdf6e3` | base3          |
| foreground            | `#657b83` | base00         |
| selection             | `#eee8d5` | base2          |
| keyword               | `#859900` | green          |
| string                | `#2aa198` | cyan           |
| function              | `#b58900` | yellow         |
| comment               | `#93a1a1` | base1          |
| error                 | `#dc322f` | red            |
